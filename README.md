# VeraMetrics Suite

Create a high-end, futuristic, and enterprise-grade B2B SaaS landing page and dashboard web application for "VeraMetrics (VM)" — an AI-powered cognitive assessment and certification institute for corporate leadership and high-stakes problem-solving.

### Design & Aesthetic Guidelines:

- Style: Ultra-clean, authoritative, corporate enterprise design (similar to top-tier institutional assessment and AI security platforms like Palantir or modern HR-Tech leaders).

- Color Palette: Deep executive navy blue background/accents (#0A1128), crisp slate grays, clean white typography, and sophisticated accent colors (like electric blue or subtle amber for status indicators).

- Typography: Modern sans-serif (Inter or Plus Jakarta Sans), crisp hierarchy, high contrast.

- Use clean card layouts, glassmorphism elements, and subtle glow or border effects for a cutting-edge AI touch.

### Key Pages / Sections to Build:

1. **Landing Page (Hero Section):**

   - Headline: "The New Standard in Elite Cognitive & Crisis Assessment."

   - Subheadline: "Replace guesswork with dynamic, AI-driven behavioral simulations. Certify critical thinking, ambiguity navigation, and strategic resilience."

   - CTAs: "Request Enterprise Demo" and "Explore Assessment Matrix".

   - Trust Badges section: "Trusted by forward-thinking engineering and executive teams".

2. **The 5 Core Assessment Pillars Section (Display Cards with placeholders):**

   - Showcase the 5 core tests:

     1. Ambiguity & Chaos Navigation

     2. Red-Teaming & Blindspot Hunter

     3. Ethical Integrity & Blindspot Matrix

     4. The Cascading Failure Stress Test

     5. Adversarial Negotiation & Ego Audit

   - **Crucial Requirement:** For each card/pillar, leave a dedicated, well-structured UI slot/placeholder container with a clear dashed border and a label reading: `<!-- CLAUDE_CODE_TEST_SLOT: [Test Name] (Easy, Moderate, Hard) -->` so that dynamic test cases can be injected here later.

3. **Enterprise Dashboard (Mock View for HR & Executives):**

   - A clean analytics dashboard showing candidate profiles, resilience indexes, critical thinking scores, and verified digital badge statuses.

4. **Pricing & Plans Section:**

   - Tiered B2B pricing cards: Growth ($499/mo), Professional ($1,299/mo), and Enterprise (Custom).

Ensure the code is fully responsive, modular, and cleanly structured using React components.
